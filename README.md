# Поиск кук сервисов сбора данных

Классификация кук по событиям внутри суточного окна наблюдения. На проверке по времени Precision при Recall не ниже 0,7 равен 0,737, у baseline из quickstart 0,097.

## Запуск

Python 3.12.

```bash
pip install -r requirements.txt
python solution.py
```

```
data/train.csv
data/test.csv
data/events.csv.gz
metric.py
solution.py
```

Ответ сохраняется в `submission.csv`. Время работы около 50 с. Значения random_state и число потоков зафиксированы, повторный запуск даёт тот же файл.

## Подготовка данных

Из событий удалены 4863 полных дубликата. В исходном файле порядок строк перемешан, события отсортированы по куке и времени. Платформа приведена к трём значениям: web, android и ios.

Используются только события внутри окна наблюдения. Событие captcha_shown встречается только после окна и в признаки не попадает.

## Признаки

На каждую куку строится 48 признаков.

Паузы между событиями: медиана, минимум, среднее и разброс логарифма паузы, доля пауз до 10 с, доля уникальных пауз, число заходов с перерывом больше 30 мин, число событий в минуту. Типичная пауза у ботов 25 с, у людей 60 с. Уникальных пауз у ботов 77 %, у людей 95 %, значения пауз у ботов чаще повторяются.

Время суток: средний час, число разных часов, доля событий с 0 до 6 ч.

Доля каждого из девяти типов событий.

Просмотры и поиск: число разных объявлений, категорий, городов и запросов, разнообразие категорий, глубина листания выдачи, повторные запросы и просмотры, доля продавцов-компаний.

Курсор, только для веба: доля событий с координатами, среднее и наибольшее значение по горизонтали, разброс по обеим осям, расстояние между соседними положениями.

User-agent разобран на браузер и систему, номера версий отброшены. Отдельно учитываются HeadlessChrome, несовпадение платформы с системой и число разных user-agent у куки.

Пропуски в полях объявления, поиска и курсора сохраняются, LightGBM обрабатывает их сам. Доли по этим полям считаются только по заполненным событиям. Платформа, браузер и система передаются в модель как категориальные признаки.

## Модель

LightGBM: 350 деревьев, 15 листьев, скорость обучения 0,03, минимум 30 объектов в листе, L2-регуляризация 5. Прогноз усреднён по трём значениям random_state.

Baseline взят из quickstart: случайный лес на числе событий и числе разных объявлений.

Наибольший вклад дают медианная пауза (16 %), разброс курсора по горизонтали (11 %), доля уникальных пауз (8 %) и число разных городов (6 %).

## Проверка

Окна теста идут с 20 по 26 апреля, окна обучения с 6 по 19 апреля. Проверка тоже по времени: пять отрезков по два дня, модель обучается на всех днях до начала отрезка. Метрика считается через `metric.py`.

| Отрезок | Кук | Ботов | Константа | Baseline | LightGBM |
|---|---|---|---|---|---|
| 10-11 апреля | 1808 | 161 | 0,089 | 0,107 | 0,698 |
| 12-13 апреля | 1660 | 120 | 0,072 | 0,084 | 0,730 |
| 14-15 апреля | 1627 | 135 | 0,083 | 0,108 | 0,758 |
| 16-17 апреля | 1453 | 126 | 0,087 | 0,089 | 0,730 |
| 18-19 апреля | 1238 | 94 | 0,076 | 0,098 | 0,767 |
| Среднее | | | | 0,097 | 0,737 |

## Эксперименты

| Вариант | Среднее |
|---|---|
| Все признаки без доли уникальных пауз | 0,713 |
| С возрастом куки | 0,723 |
| С долей самой частой паузы | 0,718 |
| С долей подряд идущих событий одного типа | 0,701 |
| С долей контактов после просмотра объявления | 0,720 |
| С долей уникальных пауз | 0,737 |

Доля уникальных пауз улучшила результат на всех пяти отрезках и вошла в решение. Прирост от остальных вариантов меньше разброса между отрезками. Для модели проверялись 250 и 500 деревьев, 7 листьев, минимум 15 объектов в листе и вес класса ботов 3, результат менялся от 0,715 до 0,738.

## Ограничения

Разметка построена на трафике нескольких известных сервисов, сервис с другим поведением может получить низкую оценку. Ботов на каждом отрезке проверки от 94 до 161, поэтому разница меньше 0,02 может быть случайной. Модель опирается в основном на паузы и курсор, их можно подделать.

## Библиотеки

pandas, numpy, scikit-learn и LightGBM. Все работают локально, внешние сервисы и языковые модели не используются. Версии указаны в `requirements.txt`.
